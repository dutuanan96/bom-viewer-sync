# 04. 工程变更 (ECN) 与版本生命周期

## 一、产品版本双轨机制

- **`currentRevision` (当前设计版)**: 研发与工程正在编辑中的最新版 (如 `B.1`)。
- **`effectiveRevision` (当前生效版)**: 车间产线正在执行生产的正式版 (如 `A`)。
- **历史发布版本 (`revisions`)**: 必须保持 100% 绝对不可篡改。

---

## 二、标准 ECN 变更控制 SOP

```
[CAD图纸变更] -> [Where-Used全系反查] -> [AI生成提议卡片] -> [管理员界面审核] -> [发布生效]
```

1. **图纸核验**：确认 2D 图纸尺寸，计算精确下料长度 L_cut，校验共用零件 CDN 图纸 URL。
2. **共用件防误伤反查 (Where-Used)**：修改或替换前，必须反查该物料在全系 22 款产品中的使用情况，严禁只顾单款产品而改崩其他共用系列。
3. **定额防缺料校验**：更新 BOM 定额时，必须复核 `N_cuts * L_cut <= L_raw`，确保留有 50mm ~ 110mm 夹料余量。
4. **结构化提议提交**：使用标准 Proposal 接口提交本地卡片，由管理员最终审核批准写入 GitHub。
