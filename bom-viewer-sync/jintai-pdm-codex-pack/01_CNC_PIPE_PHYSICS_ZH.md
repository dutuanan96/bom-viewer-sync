# 01. CNC 切管物理与采购防缺料法则

## 一、激光切管机夹料物理本质
自动数控激光切管机加工方管时，旋转卡盘需要夹持管材尾端以保持钢管旋转稳定。
- **夹料尾料残余极限**：Waste_min ≈ 50mm ~ 70mm。
- **合格夹料窗口**：50mm <= 尾料残余 <= 110mm（最佳黄金段为 70mm ~ 85mm）。
- 若残余 < 50mm，卡盘夹持不足会导致管材晃动打刀或切断时跌落；若残余 > 110mm 则属于原材定尺选型过长，造成钢材严重浪费。

---

## 二、通用数学推导公式

设定：
- **L_raw**: 钢管原料采购长度 (从规格中提取，如 `长度 6013mm`)。
- **L_cut**: 零件实际切割长度。
- **Waste_min**: 最小夹料安全余量（默认取 70mm）。

### 1. 最大可切刀数：
```
N = Math.floor((L_raw - 70mm) / L_cut)
```

### 2. 子 BOM 原材料消耗定额：
```
Rate = 1 / N
```

### 3. 实际尾料残余：
```
尾料残余 = L_raw - (N * L_cut)
```

## 三、采购零缺料铁律与事故案例分析

### 铁律：
```
N * L_cut <= L_raw
```

### 经典案例：41底脚计算事故与纠正
- **零件**：`ZJG150641BH`（41底脚，实际切割长度 41.5mm）。
- **原材料**：`FG1515066013`（长度 6013mm）。
- **错误算法 (定额 0.006897 = 1/145)**：
  - 理论刀数 = 145 刀。
  - 所需钢材 = 145 * 41.5mm = 6017.5mm > 6013mm（原材根本不够长！）。
  - **严重后果**：采购部门接到 10,000 件订单，按 10,000 * 0.006897 下单购买 69 根钢管；车间实际切出 69 * 143 = 9,867 件，**直接短缺 133 件底脚（整整少买了 1 根 6 米钢管），导致整批订单无法装箱停产！**
- **标准化正确算法 (定额 0.006993 = 1/143)**：
  - 实际刀数 = Math.floor((6013 - 70) / 41.5) = 143 刀。
  - 总切长 = 143 * 41.5mm = 5934.5mm。
  - 尾料残余 = 6013 - 5934.5 = **78.5mm**（完美落在 70~85mm 黄金夹料段）。
  - 采购部门下单 70 根管 (10,000 * 0.006993 = 69.93 ≈ 70)，车间产出 70 * 143 = 10,010 件（保质足量交付且有 10 件安全余量）。
