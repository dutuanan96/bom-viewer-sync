# 02. CAD 几何展开与构件参数法则

## 一、连续倒 U 型折弯外框 (侧框、无灯中框)

外框采用 15×15×0.6T 钢管在数控弯管机上一体弯折成型。
图纸名义标注为 `高 x 宽 x 深`（例如 `647x290x15mm`）：

1. **装配底部带螺纹塑料管塞 (`M6GS1515BH/WH`)**:
   - 管塞外翻凸边厚度 3mm。
   - 垂直高度实切：`H_实切 = H_名义 - 3mm`。
   - 下料总长：
     ```
     L_下料 = (H_名义 - 3mm) * 2 + W_名义
     ```
   - *示例*：`647x290x15mm` 侧框 -> (647 - 3) * 2 + 290 = 1578mm。
     使用 `FG1515064804` (4804mm)：切 3 个 = 4734mm，尾料 70mm，定额 `0.333333` (1/3)。

2. **采用平齐焊接圆螺母 (`M6YLM139`)**:
   - 螺母内嵌焊接平齐管口，无外凸。
   - 下料总长：
     ```
     L_下料 = H_名义 * 2 + W_名义
     ```
   - *示例*：`584x290x15mm` 中框 (`LGS033`) -> 584 * 2 + 290 = 1458mm。
     使用 `FG1515065900` (5900mm)：切 4 个 = 5832mm，尾料 68mm，定额 `0.25` (1/4)。

## 二、复合焊接中框与 LED 贴灯条铁片结构

适用于带 LED 灯带的电视柜中框（`LGS031`, `LGS131`, `LGS231`, `LGS420`, `LGS421`, `LGS043` 等）：
顶部为粘贴灯带平面，结构拆解为 4 个子部件：
1. **2 根垂直立柱 (前中框 & 后中框)**:
   - 单根实切高度 = `H_名义 - 3mm`（底装管塞）。
   - 1 个中框合计钢管 = `(H_名义 - 3mm) * 2`。
   - *示例*：576 高度中框 -> (576 - 3) * 2 = 1146mm。
     使用 `FG1515065814` (5814mm)：切 5 套 (10根) = 5730mm，尾料 84mm，定额 `0.2` (1/5)。
2. **1 根底部短横梁**:
   - 实切长度 = `W_名义 - 30mm`。
   - 290 宽配 260mm（22根/管，定额 `0.045455`）；335 宽配 305mm（20根/管，定额 `0.05`）。
3. **1 块顶部左右中框铁片**:
   - 290 宽配 `2601502ZHKTP` (260×15×2mm)；335 宽配 `3051502ZHKTP` (305×15×2mm)。
4. **五金件**: 2 个 M6 底管塞 + 1 个侧面 M6 六角拉铆螺母。

## 三、分体拼接横梁与 80mm 内衬套

超长电视柜长横梁拆分为左右两段拼接以缩小包装箱体积：
1. **主管身下料长度**:
   ```
   L_下料 = L_总成名义长 - 40mm
   ```
2. **内部加强衬套管**:
   - **固定长度 80mm**（中心左右各探出 40mm）。
   - 15×15 方管配：`FG132132105190` (13.2×13.2×1Tmm, 5190mm)，64 刀/管，定额 `0.015625` (1/64)。
   - 30×15 扁圆管配：`FG28136065190` (28×13.6×0.6Tmm, 5190mm)，64 刀/管，定额 `0.015625` (1/64)。

## 四、支撑框 (U 型加强支撑)

中间承重支撑构件：
- 规格标注格式：`[宽] x [高] x 15mm`（例如 `335x178x15mm`）。
- U 型下料长度：`L_下料 = 高 * 2 + 宽 = 178 * 2 + 335 = 691mm`。
- 配套五金：4 个焊接连接片 (`LJP16143`) + 2 个焊接圆螺母 (`M6YLM139`)。
- 使用 `FG1515065598` (5598mm)：切 8 个 = 5528mm，尾料 70mm，定额 `0.125` (1/8)。
