# 03. 物料五大分类与标准五金库

## 一、物料五大本体分类 (Material Ontology)

| 类别键值 | 中文分类 | 范围与说明 |
| :--- | :--- | :--- |
| `metal` | 金属 / 钢 / 铁 / 铝 | 结构方管 (Q195/Q235)、钢板、拉杆、角码、螺丝、螺母、扳手等。 |
| `woodComposite` | 木质 / 板材 / 中纤板 / 刨花板 | 顶板、层板、底板（带三聚氰胺贴面、封边）。 |
| `textile` | 布艺 / 织物 / 无纺布 | 无纺布抽屉、折叠布斗、纸板加固布箱。 |
| `polymer` | 塑料 / 尼龙 / PP / ABS | 塑料管塞、脚垫尼龙底座、理线扣、插座塑料壳。 |
| `packaging` | 包材 / 纸箱 / 泡沫 / EPE | 5 层邮购瓦楞纸箱、EPE 护边泡沫、护角、PE 袋。 |
