# 03. Material Catalog & Hardware Ontology

## 1. Five Main Material Families (5 Họ vật tư chính)

The JinTai PDM catalog classifies all materials into 5 strict ontology families:

| Family Key | Chinese Term | Vietnamese Term | Scope & Description |
| :--- | :--- | :--- | :--- |
| `metal` | 金属/钢/铁/铝 | Kim loại / Thép / Sắt / Nhôm | Structural square tubes (Q195/Q235), steel plates, cross wire tension rods, brackets, screws, nuts. |
| `woodComposite` | 中纤板/刨花板/木/板材 | Gỗ công nghiệp / PB / MDF | Top panels (顶板), shelf panels (层板), bottom boards with melamine finish. |
| `textile` | 布/织物/无纺布 | Vải / Dệt / Vải không dệt | Non-woven fabric drawers (布抽), foldable bins, cardboard-reinforced cloth boxes. |
| `polymer` | 塑料/尼龙/PP/ABS | Nhựa / Polymer / Nylon | Pipe end caps, leveling foot nylon pads, plastic wire clips, power socket housings. |
| `packaging` | 纸箱/泡沫/EPE/包材 | Bao bì / Thùng carton / Xốp EPE | Mail-order standard 5-ply cartons (A=B / K=K), EPE edge guards, corner protectors, polybags. |

## 2. Standard Raw Metal Profiles (Mã phôi ống sắt tiêu chuẩn)

All structural tube parts in JinTai products derive from 27 canonical raw tube codes (`FG*`):

1. **Main Square Tube (15x15x0.6Tmm)**:
   - `FG1515064804` (4804mm), `FG1515064876` (4876mm), `FG1515064930` (4930mm)
   - `FG1515065011` (5011mm), `FG1515065382` (5382mm), `FG1515065430` (5430mm)
   - `FG1515065464` (5464mm), `FG1515065566` (5566mm), `FG1515065598` (5598mm)
   - `FG1515065630` (5630mm), `FG1515065663` (5663mm), `FG1515065680` (5680mm)
   - `FG1515065718` (5718mm), `FG1515065766` (5766mm), `FG1515065814` (5814mm)
   - `FG1515065846` (5846mm), `FG1515065900` (5900mm), `FG1515065935` (5935mm)
   - `FG1515065994` (5994mm), `FG1515066013` (6013mm), `FG1515066091` (6091mm)
   - `FG1515066150` (6150mm), `FG1515066182` (6182mm)
2. **Main Flat Oval/Rectangular Tube (30x15x0.6Tmm)**:
   - `FG3015065014` (5014mm), `FG3015066550` (6550mm)
3. **Inner Reinforcement Insert Sleeve Profiles**:
   - `FG132132105190` (13.2x13.2x1.0Tmm, 5190mm) - For 15x15 square tubes.
   - `FG28136065190` (28x13.6x0.6Tmm, 5190mm) - For 30x15 rectangular tubes.
